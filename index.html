Senior Software Developer

Nov 2024 — Present

Lifemaan · Surat, Gujarat

  • Rebuilt pharmacy billing as its own isolated microservice — separate database, separate auth boundary — so a slow query or bug there could never take down anything else. At the core sits a two-stage DRAFT → CONFIRM state machine: a bill is created editable, in DRAFT, while stock, pricing and insurance checks run in the background, and only becomes a locked, final record once every check clears. That one guardrail is what actually moved the needle on the 40% drop in billing discrepancies — almost every dispute we used to see traced back to a bill that got finalized before validation had caught up.
  • Swapped a tightly-coupled, synchronous prescription-to-pharmacy flow for a Kafka pipeline: partitioned consumer groups process orders per branch in parallel while keeping order within a branch, so stock checks and order creation no longer block on each other.
  • Went hunting for slow paths across the stack — cache-aside with TTL invalidation cut drug-catalog DB reads ~40%, distributed Redis locks stopped two billers from confirming the same stock at once, and re-tuning indexes against real explain() output cut reporting latency ~45%.
  • Took on a data-integrity project nobody wanted: unifying 70,000+ drug records into a clean 200k-record master list without breaking a single existing reference. Shipped alongside it a 31-flag rollout system so changes could go live one clinic at a time instead of all-or-nothing.
  • Mentored two junior engineers on API design and reviews, cutting PR round-trips ~30%. Outside of delivery work, I keep a standing habit of daily DSA practice — arrays, graphs, DP, system design — mostly to keep the problem-solving muscle sharp for the harder architecture calls.
